Situs portofolio pribadi Narendra Heryan Syahputra, Back-end Developer dan mahasiswa S1 Sistem Informasi Universitas Dian Nuswantoro, Semarang.

🔗 **Live:** https://narendra0610.github.io/GANTI-NAMA-REPO/

## Fitur

- Tema gelap dengan tombol pengalih ke mode terang
- Dua bahasa (Indonesia / English) dengan tombol pengalih
- Hero berbentuk kartu terminal yang menampilkan profil dalam format JSON
- Bagian Tentang, Keahlian, Proyek, Pengalaman, Sertifikat & Penghargaan, dan Kontak
- Sertifikat dan penghargaan ditampilkan dalam dropdown (accordion)
- Menu yang menyorot bagian yang sedang dibaca (scrollspy)
- Form kontak yang membuka WhatsApp dengan pesan terisi
- Responsif untuk desktop dan mobile

## Teknologi

- HTML5, CSS3, JavaScript (tanpa framework)
- [Bootstrap 5.3.8](https://getbootstrap.com/) (dimuat lokal dari folder `bootstrap/`)
- Google Fonts: Bricolage Grotesque, DM Sans, JetBrains Mono

## Struktur folder

```
.
├── index.html        # Halaman utama (sudah diberi keterangan per bagian)
├── bootstrap/        # Bootstrap 5.3.8 (css & js)
├── css/style.css     # Gaya kustom dan warna tema
├── js/main.js        # Teks dua bahasa, tema, dan form kontak
└── img/              # Foto profil, screenshot proyek, gambar sertifikat
```

## Menjalankan secara lokal

1. Unduh atau clone repositori ini:
```bash
   git clone https://github.com/Narendra0610/GANTI-NAMA-REPO.git
```
2. Buka `index.html` di browser. Tidak perlu instalasi apa pun.

## Deploy ke GitHub Pages

1. Buka **Settings → Pages** di repositori ini.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
4. Tunggu beberapa menit sampai situs aktif di alamat yang tertera.

## Cara mengubah isi

- **Teks dan terjemahan:** `js/main.js` (kamus `T`, bagian `id` dan `en`)
- **Warna tema:** `css/style.css` (blok variabel di bagian atas)
- **Skill, proyek, pengalaman, dan kontak:** `index.html`. Setiap bagian diberi komentar petunjuk.
- **Foto dan gambar:** timpa file di folder `img/` dengan nama yang sama.
